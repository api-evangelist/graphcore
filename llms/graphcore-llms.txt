# Graphcore

> Graphcore builds the Intelligence Processing Unit (IPU), a processor purpose-built for AI/ML, and the Poplar SDK software stack that programs it. The developer surface is software tooling (Poplar, PopART, PopTorch, PopLibs) rather than a public REST API. Graphcore is part of SoftBank Group. This file was generated by the API Evangelist enrichment pipeline from the catalog profile and public developer surface; no provider-published llms.txt exists (docs.graphcore.ai/llms.txt and www.graphcore.ai/llms.txt both return 404).

## Developer tooling
- [PopTorch](https://github.com/graphcore/poptorch): PyTorch interface for the IPU.
- [PopART](https://github.com/graphcore/popart): Poplar Advanced Runtime (inference + training graph execution, ONNX import).
- [PopLibs](https://github.com/graphcore/poplibs): Poplar libraries of higher-level math and ML functions.
- [Examples](https://github.com/graphcore/examples): Reference ML applications optimised for Graphcore IPUs.
